# Mac 刷闪助手 · 首次启动

1. 把整个 ZIP 解压到 Mac 本地（不要在 ZIP 预览里运行）。
2. 双击 `启动助手.command`。
   - 包里已带本机编译好的 `.app` 和校验文件，源码没改动时直接启动，不会重新编译。
   - 如果改过 Swift 源码或构建脚本，会自动用本机 Swift 编译器重新构建。
   - 首次会创建 Python 环境并安装依赖（需要联网）。
3. 如果系统不允许打开，右键 `启动助手.command` →「打开」。
4. 启动失败时终端会保留报错，同时写入同目录 `启动诊断.log`。
5. 通知凭据不随包分发：需要喵提醒时，在「设置」里重新填写喵码。

需要 macOS 14+、Apple Silicon、Python 3.11+；只有重新编译时才需要 Xcode Command Line Tools。
