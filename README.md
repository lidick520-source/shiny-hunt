# 刷闪助手（PokeMMO · Mac）

在 Mac 上自动刷 PokeMMO 闪光。三种模式三选一：

- **白嫖闪**：选一个点位（帆巴市轻飘飘、琉璃市鲤鱼王……），按 5 遇怪 → 确认是目标怪群 → 查闪光 → 逃跑；
  每 6 轮按 4 回院补 PP → 走回点位 → 冲浪继续，无限轮回。
- **PP果定点**：站在任意固定点位，只按 5 → 查闪光 → 逃跑，一直循环；不回院、不走路。
- **单遇（走路单遇）**：站进草丛（如矢车森林），左右（或上下）来回短走 → 遇怪 → 查闪光 → 逃跑，一直循环；
  不用甜甜香气、不回院。没逃掉会自己再点逃跑（最多 6 次）；走 90 秒没遇怪就停（多半不在草丛里）。队首带只速度快的。

三种模式都有：**出闪提醒**（立即停止，喵提醒发到手机，电脑上响铃弹窗）和**随机换频道**（每 40–50 分钟）。
遇到弹窗、游戏被切走会自己恢复；**发现闪光或验证码立即停止，永远不会被自动恢复跳过。**

## 日常使用

1. 打开 PokeMMO：窗口模式，内容区 1024×768；甜甜香气绑定 `5`，瞬移绑定 `4`。
2. 双击桌面上的 **「打开刷闪助手.command」**（等同于本文件夹里的 `启动助手.command`）。
   助手会自动停靠在游戏窗口右边；右边放不下时先把游戏挪到屏幕左边。
3. 站在刷怪点，点 **「开始刷闪」**。不需要预览或校准，助手会自己找到游戏并保持在前台。
4. 停止：按 **F8**（运行中游戏会被一直拉回前台，点助手窗口只有 4 秒时间）。

白嫖闪点位（`spots.py`，一个一个补全）：

| 点位 | 状态 |
|---|---|
| 帆巴市 · 轻飘飘 | 已实测（2026-10-18，227 轮） |
| 琉璃市 · 鲤鱼王 | 待实测：先站到点位点「测试回院路线」 |

新点位第一次用：站在刷怪点，点「测试回院路线」，助手走一遍去医院 → 回点位 → 冲浪就停，
每一步截图在 `diagnostics/hospital-route/`，用来校正路线。

## 出问题时看哪里

- `diagnostics/incidents/<时间>/`：每次出问题（含自动恢复）的截图 `screen.png` 和前 60 行日志，保留最近 15 份。
- `diagnostics/channel-switch/`、`diagnostics/hospital-route/`：最近一次换频道、去医院每一步的截图。
- `run.log`：完整运行日志。`启动诊断.log`：启动 / 编译记录。

`启动助手.command` 会自动重新编译（需要 Xcode Command Line Tools），编译失败时保留旧的应用。

**不要提交 `notification.json`**（里面是喵码）；`.gitignore` 已排除它和所有运行时文件。
